# Slack Threads

Десктопное приложение для macOS: читать рабочие Slack-треды по-русски и отвечать
в них по-английски.

Вы добавляете тред по ссылке — приложение скачивает его целиком, переводит на русский
и складывает к себе. Дальше тред читается как обычная переписка на родном языке.
Ответ вы пишете по-русски, приложение переводит его на английский и рядом показывает
обратный перевод — чтобы вы своими глазами увидели, что именно уйдёт в Slack, — и
отправляет прямо в тред от вашего имени.

Что ещё умеет:

- **«Суть»** — короткий блок в начале треда: о чём обсуждение, к чему пришли и что
  ждут от вас.
- **Тема треда** в списке слева — как тема письма: «Ошибка CVV в Ecommpay».
- **«Обновить»** — перечитывает тред и переводит только новое и изменившееся. Правки
  старых сообщений тоже подхватываются (сверка идёт по хешу текста).
- Единый словарь: весь тред переводится в одной долгоживущей сессии переводчика,
  поэтому термины не разъезжаются от сообщения к сообщению.
- Архив (перестать обновлять, перевод сохранить) и удаление треда.

Всё хранится локально, в SQLite. Никакого сервера нет.

## Что уходит наружу

Стоит понимать до установки:

- **Текст тредов отправляется в Anthropic** — перевод делает `claude` CLI, который
  ходит в API под вашей подпиской. Если рабочая переписка не может покидать периметр
  компании, приложение вам не подходит.
- **В Slack** приложение ходит только за тем, что вы попросили: конкретный тред,
  имена авторов, отправка вашего ответа.
- Больше никуда. Токен лежит в системном keychain, переписка — в локальном файле базы.

# Установка

Всё делается один раз и занимает минут двадцать, из которых половина — ожидание
апрува Slack-приложения, если в вашем воркспейсе он требуется.

## Шаг 1. Что должно быть на компьютере

Нужен macOS (проверялось на Apple Silicon) и четыре вещи. Проверить, чего не хватает:

```sh
go version      # нужен Go 1.25+
node -v         # нужен Node.js 20+
claude --version
wails version
```

Чего нет — ставится так:

```sh
# Homebrew, если его ещё нет: https://brew.sh
brew install go node

# claude CLI
curl -fsSL https://claude.ai/install.sh | bash

# Wails — сборщик десктопных приложений на Go
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

После установки `wails` может не находиться: он кладётся в `$(go env GOPATH)/bin`.
Добавьте в `~/.zshrc`:

```sh
export PATH="$PATH:$(go env GOPATH)/bin"
```

## Шаг 2. Вход в claude

Переводчик работает через ваш аккаунт Anthropic — отдельный API-ключ не нужен,
достаточно подписки. Войдите один раз:

```sh
claude
```

Команда откроет браузер и попросит залогиниться; после этого её можно закрыть
(`/exit`). Проверить, что всё работает:

```sh
claude -p "скажи привет"
```

Если в ответ пришёл текст — переводчик готов.

> Перевод тратит лимиты вашей подписки. Тред на 20 сообщений — это примерно
> три обращения к модели.

## Шаг 3. Slack-приложение

Приложению нужен **user-токен** (`xoxp-`), то есть доступ от вашего имени.
Бот здесь не годится: он не видит приватные каналы и личку и не может писать за вас.

1. Откройте <https://api.slack.com/apps> → **Create New App** → **From scratch**.
   Имя любое (например, `Slack Threads`), воркспейс — ваш рабочий.
2. Слева **OAuth & Permissions** → секция **Scopes** → **User Token Scopes**
   (именно User, не Bot). Добавьте ровно эти шесть:

   | Scope | Зачем |
   |---|---|
   | `channels:history` | читать треды в публичных каналах |
   | `groups:history` | то же в приватных каналах |
   | `im:history` | личные сообщения |
   | `mpim:history` | групповые личные сообщения |
   | `users:read` | имена авторов сообщений |
   | `chat:write` | отправка вашего ответа в тред |

3. Наверх страницы → **Install to Workspace** → разрешить.

   Во многих компаниях самостоятельная установка приложений запрещена: тогда кнопка
   отправит запрос администратору, и придётся подождать апрува. Это нормально —
   приложение приватное, видите его только вы.

4. Скопируйте **User OAuth Token** — длинная строка, начинается с `xoxp-`.
   Она понадобится при первом запуске.

## Шаг 4. Сборка приложения

```sh
git clone https://github.com/pvarganov/slack-threads.git
cd slack-threads
make build
```

Сборка занимает пару минут: Wails собирает Go-код, ставит зависимости фронтенда
и упаковывает всё в `build/bin/slack-threads.app`.

Перенесите приложение к остальным, чтобы оно появилось в Spotlight и Launchpad:

```sh
cp -R build/bin/slack-threads.app /Applications/
```

## Шаг 5. Первый запуск

Откройте **slack-threads** из Launchpad или Spotlight (⌘Space).

macOS может сказать, что приложение «не удаётся проверить» — оно собрано вами же
и не подписано сертификатом разработчика. Откройте Системные настройки →
Конфиденциальность и безопасность, найдите сообщение про slack-threads и нажмите
**Открыть всё равно**. Спрашивается один раз.

Дальше приложение попросит токен — вставьте `xoxp-…` из шага 3 и сохраните.
Токен уйдёт в системный keychain; macOS спросит разрешение на доступ к нему, лучше
ответить «Всегда разрешать», иначе вопрос будет повторяться при каждом запуске.
В файлах конфигурации и в базе токен не хранится.

Если чего-то из шести scopes не хватает, приложение прямо скажет каких.

# Как пользоваться

**Добавить тред.** В Slack откройте меню сообщения (⋯) → **Copy link**. Нажмите
«Добавить по ссылке» и вставьте ссылку. Подойдёт ссылка на любое сообщение треда,
не обязательно на первое.

**Сколько ждать.** Перевод — небыстрая операция, время уходит на генерацию текста:
примерно **45 секунд на каждые 10 сообщений**, плюс ход на «Суть». Тред на 20 сообщений
добавляется около двух минут, прогресс виден в строке состояния. Это не зависание.

**Читать.** Слева список тредов, справа переписка по-русски. Наверху блок «Суть».
Галочка «Показать оригинал» открывает под каждым переводом английский исходник.
Ссылки внутри сообщений открываются в браузере.

**Обновить.** Кнопка «Обновить» на треде перечитывает его из Slack и переводит только
то, что появилось или изменилось. «Обновить все» — то же самое для всего списка.
Автоматического обновления нет: Slack быстро упирается в лимиты, поэтому момент
выбираете вы.

**Ответить.** Внизу поле «Ответ по-русски». Напишите ответ, нажмите «Перевести» —
появится английский текст и его обратный перевод на русский. Прочитайте обратный
перевод: это проверка, что смысл не поехал. Английский текст можно поправить руками.
«Отправить» отправляет его в тред от вашего имени.

**Убрать с глаз.** «В архив» — тред перестаёт обновляться, перевод остаётся (архивные
показываются по галочке слева). «Удалить» — стирает тред со всеми переводами насовсем.

# Если что-то не так

| Симптом | В чём дело |
|---|---|
| «Не найден бинарник `claude`» | CLI не установлен или лежит в необычном месте. Приложение ищет его в `PATH`, `~/.local/bin`, `~/.claude/local`, `/opt/homebrew/bin`, `/usr/local/bin`. Нестандартный путь задаётся переменной `SLACK_THREADS_CLAUDE_BIN`. |
| Перевод висит и не двигается | Проверьте, что `claude -p "привет"` в терминале отвечает. Если у вас настроены хуки Claude Code — они на перевод не влияют, приложение запускает CLI без пользовательских настроек. |
| «Не хватает прав» со списком scopes | В Slack-приложении добавлены не все шесть User Token Scopes. Допишите недостающие и переустановите приложение в воркспейс — токен после этого меняется, вставьте новый. |
| Ответ не отправляется, что-то про `slack_connect` или `restricted_action` | Канал расшарен с другой компанией, и политика воркспейса запрещает отправку через приложения. Английский текст остаётся в черновике — скопируйте и отправьте руками из Slack. Обойти нельзя. |
| Добавление длинного треда идёт минутами | Slack жёстко ограничивает чтение тредов для приложений не из Marketplace — порядка одного запроса в минуту. Приложение уважает лимит и ждёт, это ожидаемо. |
| Приложение не открывается, Gatekeeper ругается | Системные настройки → Конфиденциальность и безопасность → «Открыть всё равно». |

## Обновить приложение до свежей версии

```sh
cd slack-threads
git pull
make build
cp -R build/bin/slack-threads.app /Applications/
```

Ваши треды, переводы и токен при этом не теряются: база лежит отдельно, в
`~/Library/Application Support/slack-threads/threads.db`, и переносится между версиями
автоматически.

## Настройки через переменные окружения

В обычной работе не нужны, всё берётся из значений по умолчанию.

| Переменная | По умолчанию | Что меняет |
|---|---|---|
| `SLACK_THREADS_MODEL` | `opus` | модель перевода; `sonnet` заметно быстрее |
| `SLACK_THREADS_CLAUDE_BIN` | `claude` | путь к бинарнику переводчика |
| `SLACK_THREADS_DB` | `~/Library/Application Support/slack-threads/threads.db` | путь к базе |
| `SLACK_THREADS_TOKEN` | — | токен в обход keychain (тогда в интерфейсе он только для чтения) |
| `SLACK_THREADS_RESPONSE_TIMEOUT` | `5m` | таймаут одного хода перевода |
| `SLACK_THREADS_IDLE_TIMEOUT` | `15m` | сколько живёт неиспользуемая сессия переводчика |
| `SLACK_THREADS_SLACK_TIMEOUT` | `30s` | таймаут одного запроса к Slack |

# Ограничения

- **Только треды.** Одиночное сообщение канала вне треда, файлы, вложения и канвасы
  не импортируются; от сообщения остаётся его текст.
- **Нет автоматического обновления** — по кнопке, сознательно (см. лимиты Slack).
- **Удалённые сообщения** остаются локально с пометкой и переводом: история не теряется,
  но со Slack один в один уже не совпадает.
- **Пользовательские настройки и хуки Claude Code в переводе не участвуют.** Подпроцесс
  запускается с `--setting-sources ""`: иначе, например, хук `MessageDisplay` переписывал
  бы готовый перевод, а его таймаут прибавлялся бы к каждому сообщению треда.
- **Перевод зависит от `claude` CLI.** Формат его потока событий не гарантирован
  стабильным между версиями; после крупного обновления CLI контракт стоит перепроверить
  (см. `docs/claude-cli-contract.md`).
- **Подпись и нотаризация не предусмотрены** — приложение собирается и запускается
  локально вами.

# Для разработчиков

```sh
make test        # go test ./... + тесты фронтенда
make test-short  # то же без build/vet-смоука
make lint        # golangci-lint
make dev         # запуск с live reload
make build       # .app в build/bin
```

Версия проставляется линковкой:

```sh
wails build -ldflags "-X github.com/pavelvarganov/slack-threads/internal/app.Version=1.0.0"
```

SQLite подключён через `modernc.org/sqlite` (чистый Go), cgo не требуется.

## Структура

```
cmd/slack-threads/   точка входа (дубль main.go в корне — его собирает wails)
internal/permalink/  разбор и обратная сборка ссылок Slack
internal/store/      SQLite: схема, миграции, репозитории
internal/slackapi/   HTTP-клиент: conversations.replies, users.info, chat.postMessage
internal/translate/  сессии claude, промпты, перевод, «Суть», черновики ответов
internal/sync/       оркестрация: добавить, обновить один, обновить все
internal/config/     конфиг и токен в keychain
internal/app/        Wails-биндинги
frontend/            HTML/CSS/JS без фреймворков
```

Внешние зависимости (HTTP API Slack, бинарник `claude`) закрыты интерфейсами
и подменяются в тестах: тесты не ходят в сеть и не запускают `claude`.
